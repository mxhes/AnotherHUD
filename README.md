# AnotherHUD

AnotherHUD replaces the default unit frames and action bars of WoW Forever with its own, and plugs them into Blizzard's Edit Mode so you can move and size them the usual way.

**Status: in development.** There is nothing to install yet.

## Unit frames

AnotherHUD draws its own Player, Target, Target of Target, Focus and Pet frames in place of Blizzard's. Move them in Edit Mode; each has a settings panel there (size, texts, look, cast bar, auras, fading). The Player's cast bar can be detached and moved as its own frame ("Detach cast bar"). Turn single frames off in the AnotherHUD box under the Edit Mode window; turning one back to Blizzard's needs a /reload.

It is part of a small suite of addons together with AnotherLedger.
