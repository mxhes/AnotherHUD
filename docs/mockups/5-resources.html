Mockup 5: Class resources and totem bar

The class resource bar is its own Edit Mode frame, attached under the Player frame by default (200 px wide). Each resource has its own color; partly filled points (runes recharging, soul shard fragments, essence regenerating) fill up dimmed with the time on them. Totem bar: one slot per totem / guardian, using the approved action button look, the time left on the icon and a thin bar under it that drains.
